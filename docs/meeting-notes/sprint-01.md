# Prvi sastanak

Na prvom sastanku dogovoren je tehnološki skup za razvoj aplikacije ZG Customs te je definirano 25 glavnih zadataka koji obuhvaćaju zahtjeve, razvoj, ispitivanje i isporuku projekta.

## Dogovorene tehnologije

| Dio sustava | Tehnologije |
| --- | --- |
| Korisničko sučelje | React, TypeScript |
| Poslužiteljski dio | Java, Spring Boot |
| Baza podataka | PostgreSQL |
| Postavljanje aplikacije | Microsoft Azure |
| Kontejneri | Docker |
| Izgradnja poslužiteljskog dijela i upravljanje ovisnostima | Maven |
| Web-poslužitelj za produkcijsko korisničko sučelje | Caddy |
| Razvoj i izgradnja korisničkog sučelja | Vite |

## Glavni zadaci projekta

| Oznaka | Dogovoreni zadatak |
| --- | --- |
| AS01 | Definirati zahtjeve i osnovu oblikovanja sustava AutoServis. |
| AS02 | Uspostaviti arhitekturu i osnovu projekta koja se može pokrenuti. |
| AS03 | Omogućiti ponovljivo postavljanje baze podataka i aplikacije. |
| AS04 | Implementirati vanjsku prijavu, registraciju i pristup prema ulogama. |
| AS05 | Omogućiti vlasniku vozila podnošenje zahtjeva za servis. |
| AS06 | Implementirati profile mehaničara i radni prostor za dodijeljene servise. |
| AS07 | Implementirati evidenciju vozila vlasnika. |
| AS08 | Implementirati obavijesti e-poštom o promjenama servisa putem vanjske usluge. |
| AS09 | Implementirati životni ciklus servisnog zahtjeva i praćenje statusa za vlasnika. |
| AS10 | Implementirati evidenciju servisnih radova i unos konačnog troška. |
| AS11 | Implementirati upravljanje zaposlenicima autoservisa. |
| AS12 | Implementirati raspoređivanje servisa i dodjelu mehaničara. |
| AS13 | Implementirati mjesečne kartične pretplate za autoservise. |
| AS14 | Isporučiti javno dostupnu aplikaciju za prvu iteraciju. |
| AS15 | Implementirati ponude dodatnih radova i njihovo odobravanje od strane vlasnika. |
| AS16 | Implementirati administraciju korisnika platforme i autoservisa. |
| AS17 | Implementirati povijest servisa vozila i pregled detaljnih računa. |
| AS18 | Implementirati pregled povijesti svih servisa unutar autoservisa. |
| AS19 | Omogućiti preuzimanje potvrda o obavljenom servisu. |
| AS20 | Implementirati ocjene i komentare nakon servisa. |
| AS21 | Implementirati statistiku servisnih usluga autoservisa. |
| AS22 | Implementirati administraciju cijena pretplata i pregled korištenja platforme. |
| AS23 | Isporučiti završnu projektnu dokumentaciju. |
| AS24 | Provesti sustavsko ispitivanje svih korisničkih uloga i prikupiti dokaze o zadovoljavanju kriterija prihvaćanja. |
| AS25 | Isporučiti integriranu završnu aplikaciju i demonstrirati projekt. |
